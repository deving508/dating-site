# Matchmaker UI 💘

A fun tinder knockoff type of dating website.

## Live Demo
https://deving508.github.io/dating-site/

## Built With
- React
- Vite
- Tailwind CSS
- GSAP

## Deployment

The app is configured to run at the domain root. This repository's root is the
folder containing this `package.json`, so leave the deployment project's root
directory as `.`. Run `npm run build` and publish the `dist` directory. Netlify
uses `public/_redirects` and Vercel uses `vercel.json` to build and serve the
app's client-side routes on direct visits and refreshes.
